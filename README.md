# Mystique Restaurants Lahore

System Architecture & Tech Stack

The platform operates as a real-time full-stack application running on localhost:3000.

It utilizes a live Supabase backend coupled with active Broadcast Channels to ensure instantaneous synchronization across user clients and kitchen displays.

Role-Based Access Control (RBAC) dynamically manages permissions, allowing users to toggle between customer views (e.g., Samiya, Customer) and administrative privileges.

Admin & Kitchen Operations Suite

MM Alam Road Management Hub: A centralized operations suite designed to oversee incoming wok and sushi station tickets, edit menu items, manage stock availability, confirm table reservations, and monitor revenue metrics.

Live Kitchen Kanban: A multi-stage tracking board divided into Incoming Tickets (awaiting kitchen confirmation), Active in Kitchen (wok and grill station preparation), and Ready/Plated (awaiting server or rider pickup).

Audio Alerts & Testing Tools: Features a toggleable Kitchen Chime ON notification system and a Simulate Customer Order button to test end-to-end routing and kitchen queue responsiveness (e.g., generating Ticket MYS-2948).

Order Filtering & Management: Allows administrative staff to filter incoming orders dynamically by fulfillment type: All Tickets, Dine In, Delivery, and Takeaway.

Customer Dining & Reservation Portal

Self-Service Ordering & Tracking: Customers can access the Customer Dining menu, manage items in the Cart, and monitor live order statuses such as Pending or Preparing via the Track Order interface.

Table Reservations: Enables guests to submit digital booking requests (e.g., reservations for 2 guests) that trigger real-time approval notifications.

Enhanced Operational Extensions & System Modules

Inventory & Menu Control Module: Real-time stock availability tracking that automatically prevents customers from ordering out-of-stock items, synchronizing directly with kitchen preparation stations.

Sales & Revenue Analytics Dashboard: Integrated reporting tools providing real-time financial tracking, peak dining hour analysis, and daily turnover metrics for restaurant management.

Customer Feedback & Review Integration: Built-in hooks displaying the establishment's 4.6-star rating from over 2,000 verified Google reviews directly on the interface to build consumer trust.

Notification & Toast Alert System: Real-time feedback banners (such as "Order Placed Successfully!" and "Table Reservation Requested") providing immediate visual confirmation for both patrons and staff.
